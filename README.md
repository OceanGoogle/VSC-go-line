this plugin's command is 'ctrl_g_go', please change key-map to this one,<br>
method:
``` 
    1. install this extension
    2. ctrl+k, ctrl+s  (hotkey map setting)
    3. search 'ctrl_g_go'
    4. bind to your favor key combo, default is ctr+g
```
usages:
```    
    go up :  line amounts + u(-,k)
        ex:   20u # up 20 lines
              5-  # up 5  lines

    go down:line amounts + d(+,j)                  
        ex:   5d # down 5 lines
        ex:   6j # down 6 lines
```    
all commmands dont need pushing "enter"
